# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
**Security → Report a vulnerability** on this repository
(<https://github.com/airalab/sensors.social/security/advisories/new>).

Do not open a public issue for a vulnerability. Include steps to reproduce and
the affected page or component. We will acknowledge the report and keep you
updated until it is fixed.

## Scope

This repository covers the sensors.social web application. Issues in the data
backend belong to [RoSeMAN](https://github.com/airalab/RoSeMAN), and issues in
the device firmware to [altruist-firmware](https://github.com/airalab/altruist-firmware).
